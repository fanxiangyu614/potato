# 专项资产图型

只在武器、载具、机械兽、生物设定页任务中读取对应小节。骨架是可改填的默认值，不是固定套餐；用户指定视图、版式、风格优先。已有合格设计直接复用，不强制先出单图再出四视图。未锁定且会影响后续整批的设计，按资产协作规则用必要代表图验证后再扩展；单个设定页本身可直接作为候选，不自动另生地基图。

共用填写项：主体及用途、已有参考图各自职责、需要展示的视角、跨视图不变量、各格必须读出的结构。删去无关项，默认中文；模型、比例、尺寸和编辑方式按当前工具能力填写，不继承来源平台参数。设计页用于视觉沟通，不将生成图标成经过尺寸或机械工程验证的制造蓝图。

## 武器／关键道具

适用：整件轮廓、厚度与功能细节需要同页说明；仅要单件亮相时不用多格。

```text
制作〈道具名〉设定页，参考图〈编号〉仅锁定〈已确认结构〉；本次只允许改变〈材质／颜色／无〉。
默认四格，可按用途删改：左上完整正面；右上完整侧面；左下〈关键功能结构〉近景；右下握持／连接部近景。
整件格显示〈尖端至尾端〉，朝向〈方向〉；侧面读出厚度与连接方式。细节格展示同一件物体对应部位，不另造零件。
跨格保留〈轮廓、部件数、连接位置、尺寸关系〉。材质对应：〈部件A→材质A〉、〈部件B→材质B〉；原有明暗／强调区域转为〈新材质中的对应对比〉。
背景与光照以结构可读为准；不添加未要求的装饰、字样或展示台。
```

检查：正侧面是否同件；细节能否在全图定位；握柄与连接结构是否连通；各格材质是否一致；整件是否被裁掉。精确标签需要可靠排版时另行制作，不依赖图像内小字作为尺寸真值。

修正例：换金属后连轮廓也变了 → “保留参考中刃部轮廓、孔位、握柄与配重，仅将外壳改为〈材质〉。”结构已错时按质量规则决定修复或重建，不用增加材质词掩盖。

## 载具

适用：需要说明主体形态、操作位与推进机制。

```text
〈载具名〉设计页。〈参考职责〉。展示同一载具的侧面、正面、俯视和三分之四透视；只保留任务需要的视图。
用途〈单人／多人及任务〉；整体尺度〈项目尺寸〉，与〈同平面驾驶者／座椅／门〉形成可读对照。
主要承重／移动结构为〈A〉，〈B〉仅辅助〈功能〉。操作位位于〈位置〉，入口与控制件可辨。
侧面展示〈底盘或滑行结构〉，正面展示〈宽度与开口〉，俯视展示〈占地轮廓与操作位〉，透视展示整体连接。
所有格保持同一底盘、推进器数量、装饰位置和材质。〈当前状态：展开／收拢等〉一致。
```

检查：人员容量和物体比例；主辅机构有无颠倒；是否变成错误使用环境的载具；俯视与侧面能否对应；翼、轮、滑橇等数量与位置是否一致。

失败→修正示例：单人沙橇变大船 → 明确仅一个操作位，并用驾驶者对照窄小船体；滑橇变轮车 → 指明中央滑橇承重滑行、侧轮仅稳定。只在项目确有这些设定时使用。

## 机械兽

适用：机械结构需保留生物原型的辨识特征。不要给普通生物自动添加驾驶舱或机甲接口。

```text
同一只〈机械兽名〉的〈所需视图〉设定页。
原型〈已定物种／虚构形态〉；辨识重点〈鼻部、喙部、角、肢体或轮廓中最关键的特征〉必须在〈指定视图〉可见。
构造〈全机械／生物与机械混合〉；表面〈板片、柔性连接、皮肤等按设定分区〉，不是泛称“机械风”。
侧面看〈轮廓与步态结构〉，正面看〈辨识特征〉，俯视或透视看〈既有接口／背部结构〉。
跨格保留肢体数、关节位置、特征比例、材质与〈休眠／展开〉状态。
```

检查：是否退化为普通近亲形态；关键特征是否被装甲遮没；全机械设定是否混入真毛皮；接口与关节能否跨格对应；名称是否残留上一资产。

修正例：全机械羽片变真羽毛 → “羽片由分层金属薄板构成，边缘与连接铰链可见”；只修本次错项，不追加源项目的青铜、发光眼或驾驶舱。

## 生物设定页

适用：生物全貌、解剖特征与比例关系需共同表达；叙事中的巨物局部镜头不套全貌页。

```text
〈生物名〉设定页，〈参考图〉锁定同一只生物的〈体型、肢体布局、头部与表面〉。
可选版式：大侧视图＋俯视图＋头部细节；按交付需要增加正面或腹面，不默认全做。
正交格无明显透视缩短；若另含透视展示格，明确标识其用途。
侧视图旁放〈有已知尺寸的对照物〉，位于同一基准面。〈体长／高度〉分别定义，不混用；文字尺寸另保留在规格中。
各格保持〈肢体对数、分节数、附着物位置、皮肤／甲壳材质〉。关键结构清晰，不以重虚化或颗粒遮挡。
```

检查：各视图结构对应、数量一致；参照物尺度合理；特殊姿态未变成新解剖；标签与图形没有错配。比例条、色板只在确有需求时加，过密就拆分信息，不承诺提高分辨率即可纠正结构。
