# 双参考动漫转真人

适用：用户同时提供真人模特图与动漫角色图，要求保留真人身份，同时借用动漫图的姿势、服装、发型设计或画面氛围，生成真人 COS 摄影、真人角色照或影视化人物图。普通 COS 随机写真、单参考换装、动漫修复不读本卡。

这不是把两张图泛化“融合”，而是先规定每张图能控制哪些字段。用户明确锁定项优先于下表。

## 参考职责

| 字段 | 真人参考图 | 动漫参考图 |
|---|---|---|
| 面部身份 | 唯一权威：脸型、五官关系、年龄感、肤色与个人辨识特征 | 不得提供眼睛大小、下巴、鼻口比例或通用动漫脸 |
| 身体 | 仅采用照片中真实可见的体型与比例证据；看不见的部分按正常真人解剖补全 | 只借动作线、身体朝向和重心，不复制夸张头身比、肢长或关节角度 |
| 姿势与构图 | 默认不继承原照片姿势和背景 | 控制机位关系、身体朝向、手势、衣摆动势及构图；与人体极限冲突时保留动作意图并修正关节 |
| 服装与配饰 | 默认不继承模特原衣，除非用户锁定 | 控制服装轮廓、分层、配色、饰品与标志性设计 |
| 发型 | 不把原发型误当身份锁；用户明确保留时除外 | 控制发型轮廓、发色与饰品，并转成真人可实现的头发或假发结构 |
| 色调与氛围 | 保持真人肤色和光影可信 | 可提供整体情绪、色彩方向与轻量动漫气息，不得把人物重新绘成插画或 CG 塑料人 |

“100% 保留身份”只能作为用户的强目标，不能当成可测量的生成保证。执行时表达为：真人图是唯一面部权威，面部身份优先于动漫风格、服装、姿势和特效；成图仍须实际查看相似度。

## 编写与执行顺序

1. **声明两图职责。** 用“图1只负责……；图2只负责……”逐字段绑定，并写出各自不得控制的字段。不要只写“参考图1、参考图2”或“融合两图”。
2. **先锁真人身份。** 描述真实面部结构、年龄感、自然皮肤、毛孔、唇纹、细小肤色变化与真实毛发；不用“完美脸”“动漫美少女脸”等覆盖个体特征。
3. **再抽取动漫设计。** 读取姿势、身体朝向、服装轮廓、发型轮廓、饰品、主配色和氛围。只写当前动漫图实际可见且任务需要的部分，不凭角色印象补版本。
4. **完成实体化翻译。** 把色块与画线改写成可制造结构：衣片层次、接缝、闭合方式、腰带与扣具、手套和靴子的穿戴关系；分别写布料织纹、皮革厚度、金属反射及重力褶皱。夸张悬浮部件改成可见支撑、固定结构或受运动带起的短暂状态。
5. **恢复摄影物理。** 明确真人摄影基底、真实光源、皮肤与衣料的不同反光、镜头景深和环境接触阴影。`4K`、`ultra-detailed`、`professional` 只能作末尾质量词，不能替代这些可见证据。
6. **最后加轻量风格。** 柔光、运动光迹或能量线放在人物轮廓周围或后方，不能遮住眼睛、双手、服装识别点和身体边界。背景默认简洁但不删除用户指定的场景。
7. **实际传入两张图。** 使用图像工具时按其引用机制传入真人图和动漫图；仅在文字中提到图片不等于完成绑定。工具无法接收两张参考或不能区分职责时，明确这一限制，不声称已实现严格双参考控制。

## 高风险姿势

动漫图若是“三分之四背身、回头看镜头、衣摆甩动、手靠近肩后”的构图，逐项写清：

- 躯干仍为背身或斜背身，头部仅转到可见所需面部特征的角度，不把整个身体偷转成正面人像。
- 颈部旋转与双肩方向一致，耳、下颌、斜方肌和锁骨关系自然；需要更清楚的脸时优先微调机位，不强扭颈部。
- 手掌、手指与肩部留出清楚轮廓，避免手臂穿过躯干、手指粘住衣料或被长发遮成一团。
- 动态外套、披风或长发有起点、受力方向和落点，并保留身体轮廓；不靠无来源的全身狂风制造动感。

## 失败定位与单次修正

| 成图问题 | 常见原因 | 修正重点 |
|---|---|---|
| 脸变成动漫脸、网红脸或两张脸混合 | 没写唯一面部权威，或把“anime aesthetic”放在人物身份前 | 重申动漫图不提供任何面部结构；把真人身份、年龄和皮肤证据前置，减弱人物上的动漫风格词 |
| 身材和关节仍是二次元比例 | 把“匹配姿势”误写成复制全部人体 | 改成只借动作线、朝向与重心；补正常骨架、颈肩关系、关节极限和落脚点 |
| 服装像贴图、乳胶或身体彩绘 | 只写服装名称与颜色，没有制造逻辑 | 补衣片分层、边缘厚度、接缝、扣具、穿戴顺序、材质差异和重力褶皱 |
| 回头姿势丢失，变成正面证件照 | 为了露脸让身体也转正 | 锁定躯干背向与肩线，只允许头部和机位提供所需面部可见度 |
| 真人身份难以辨认 | 动漫姿势遮住大部分脸，或真人图本身缺少可见信息 | 在不破坏动作意图的范围内调整机位或回头角度；仍不可见时承认身份可核验程度有限，不虚构完整相似度 |
| 发型、光效遮脸或破坏手部 | 动漫元素没有空间层级 | 将发丝、披风和光效放到轮廓外或后方，降低密度，明确眼、手和服装边缘无遮挡 |
| 真人照片原衣服或背景泄漏 | 未明确它们不属于身份字段 | 写明图1原服装、姿势和背景不继承；用户确有锁定时按字段例外处理 |

先实际看成图并集中判断。修正只针对已定位问题，沿用图片舱现有生成与修复额度；严重身份漂移、畸形或塑料化明显时直接废弃重生，不用反复局部修补挽救。
