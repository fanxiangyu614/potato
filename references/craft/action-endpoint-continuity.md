# 动作范围、首尾状态与剪辑衔接

用于动作静帧、多图连续性、首尾参考与图像资产准备。单张图片只表示一个可见时刻；多图的状态关系不等于已验证连续视频。补充镜头语言和空间预检，不另建审批流程，不要求每镜填表。用户已明确的动作、时长、结局与机位直接继承。

## 先确定事件，再写镜头

先用一句话说明本段可见结果：谁因何做了什么，最后停在什么状态。一个主要事件可以包含必要的连续动作；不机械压缩成一个动作，也不为了电影感扩写新事件。

- 分清锁定事件与执行余地。用户只要碰撞后退开、停住，就不自行增加漂移旋转、再次撞击、车门飞脱或人物的新决定。首尾资产已有的损伤需要衔接，但不能凭空确定其形成过程。
- 动作先后、幅度和停止时点用可见语言表达。保留影响结果的因果，不用未经验证的精确力学、速度或旋转角度填满空白。
- 摄影机运动另写起点、终点与揭示的信息。主体后退和摄影机后退是两件事；画面位置变化不能直接当作主体位移。没有必要的信息变化就沿用已有机位，不额外编排环绕。
- 简短不是目标。保留必要动机、人物能动性、道具归属和因果证据，删掉擅自添加的行为及重复约束。连续性记录中的不可见状态，不必强行在本镜再次展示。

最小写法按需使用：`从已发生的状态开始 → 本段动作及可见结果 → 何时停止、保持多久 → 必要的机位变化与继承项`。不以分析表代替用户要的可复制提示词。

## 动作句与速度衔接

本节为外部文本提炼的候选方法，未做生成效果验证；[来源与取舍](cinematic-visual/sources.md#帅帅导演-v4-定向吸收)不改变本页其余已有制作约束。

抽象动作词不足以确定执行时，可按需写成：`动作主体或身体部位 → 动作 → 方向／路径 → 速度与时间关系 → 接触点或终点 → 必要的物理反馈`。不是每句必填六项；已有清楚信息不重复，左右手、落脚、握点只在影响动作或衔接时明确，不从示例继承角度和速度数值。

- “利落挥动外套完成变装”可在动作细节未锁定时落成：右手握住外套领口，将衣料从画面左侧扫向右侧，覆盖镜头后在新服装画面中沿同方向继续移出；切点与不变项按[匹配转场](cinematic-visual/coverage-and-editing.md#匹配转场的锚点与切点)核对。这个例子不是默认剧情。
- 连续高速任务同时检查接近、主动作、收势和跟拍速度；不在中间塞无来源的停顿、慢准备或定势。不因“高速”取消用户明确要求的制动、蓄力或反应。
- 动作装不进已锁时长时，先减少未锁定的花式和重复动作，保留关键接触、结果及下一动作的起势；全部动作也已锁定时明确容量冲突，不能靠“极速”二字掩盖。
- 一镜到底逐段连接起止姿态、支撑和持物状态；匹配切换不是隐藏复位的借口，也不能擅自把连续镜头改成切镜。

## 首尾图片先检查能否衔接

两张静态图都正确，不代表能按要求连续运动。核对主体身份、世界中的位置与朝向、可见侧面、损伤、门窗、人物姿态，以及摄影机所在区域。

从车尾视角变成车头视角，必须分清车辆转向、摄影机绕行、两者共同变化或切镜。不能把大的视角差都塞进“轻微后退”，也不能为凑尾帧擅自安排车辆旋转。

- 首尾相容：只写完成指定事件必需的运动与时间。
- 首尾不相容：指出具体冲突，保留锁定事件，提出最小资产或镜头修正。未锁定细节可在授权范围内修正；若必须改变锁定尾帧、连续镜头或动作才成立，带着具体方案询问，不默默改戏。
- 同镜内状态变化需可见过程；切镜可省略过程，但后果、时间与空间关系必须接得上。脱落物件不能凭空恢复；不同侧面看到不同车门，不能误判为车门再生。

## 图像资产从实际用途倒推

在既有清单和分镜中记录，不强制新增文件或字段：

1. **用途**：参考负责身份、地理、状态还是构图，下一镜需要观众看清什么。
2. **入出状态**：进入本镜时已有的状态、离开时改变的状态、下一镜继承哪一版。损伤、持物手、道具归属、人物位置按剧情阶段继承。
3. **连接方式**：沿用机位、换侧、反打或连续运动；首尾资产的朝向和可见侧面是否支持它。

先确定动作与剪辑关系，再选参考角度。不要各自生成两张漂亮图片后，要求模型补出任意复杂的中间过程。只为实际使用的状态与角度制作资产，不统一要求多视图或逐动作出图。

## 相邻镜头与生成成本检查

本节的批次只用于计划和依赖管理，实际出图按 [图片质量规则](../storyboard-image-quality.md) 逐张执行：本张生成、集中验收及采用／额度内修复及复检／废弃处理结束，才开始下一张。连续镜头以已合格的上一张核对衔接；失败图不得流入下一张参考。

用于多镜头分镜、画幅改编和分集资产批量制作；复用已有清单，不增加固定表格或用户审批。

- **先查连接，再出图。**对存在状态变化的相邻镜头，回答“上一镜结束状态是什么—本镜哪些可见动作造成变化—下一镜继承什么”。动作省略必须已有足够的时间、空间与后果证据；不能用反应镜头掩盖缺失的关键事件。世界中的朝向、相对距离、接触位置与摄影机变化分开核对。新增镜头要补明确缺失事件，不能只加景别或重复已有动作。
- **动作具备执行条件。**按先后检查手脚占用、持物手、关节活动空间和道具用途。准备、操作、受力、恢复不能随意交换；例如本案例用户要求先转向顶横推行，再缠带准备撞击，不能改成缠带后打方向。该剧情安排不是现实安全操作建议或已验证的力学结论。瞄准、确认、收枪必须有前置行为，不能只用结尾摆姿代替。
- **逐图与相邻图一起看。**按剧情核对服装、人物与座椅/方向盘的关系、道具材质及缠绕、持枪手、门窗开闭与脱落、损伤与落物。分身标签不能使错误姿势或服装参考自动合格。“关键瞬间不是首帧”不能豁免该画面的空间和状态矛盾。局部修图后查看全图及受影响邻镜；没有检查整个动作段，不称整段已通过。
- **数量服从实际镜头。**用户指定一镜一图时保持一一对应，不为用满上传槽扩成A/B或首尾状态图。用户新增镜头后更新编号、总数和时长；时长用实际加总复核，不能照抄复核者口算。
- **只暂停受影响的生成，修好后继续。**发现因果或空间错误时，只暂停受影响资产的生成，继续修对应文字及邻镜；修通后仅重做必要资产，其他不受影响的工作照常完成。调用会产生真实费用或消耗额度的生成工具，必须位于用户已有的批次、次数和成本授权内；明确的生成请求覆盖相应范围内的常规调用，不因用户未填写预算表而重复确认；额外付费或扩大批次仍需相应授权。同范围授权持续有效，不逐张重复确认。未指定重试上限时，也只在有具体修正依据且既有成本授权允许时重试，同一问题重复失败后不继续追加调用。达到用户重试上限或成本边界时停止相关调用，保留可用文字、已合格资产和具体未完成项，不整批重跑，也不把失败图当作合格参考。用户改为只看文字或停止生成时，立即收缩到该范围。

此检查来自来源资料的制作纠偏，保留手脚占用、状态和参考职责方法；不把原视频案例或学习索引作为独立技能依赖。

## 图像、参考与文字分别评价

静态成图检查当前事件、身份、衣装、动作支撑、机位、受光与材质；参考图检查其实际承担的职责；提示词检查已锁定事实是否保留。单张图不能证明连续动作或视频节奏，文字检查不能替代实际看图。比较与复核必须指向真实输入和结果，不从后期整理后的呈现反推未查看的生成过程。
