# CV-LOOK · 视觉方案、题材差异与防违和

用于建立或修正一组镜头的整体色彩与成像质感，尤其是只写了“冷暖色调”、各镜观感漂移，或颗粒、光晕、雾、柔焦堆叠导致画面发糊时。单词改色、保持既有视觉方案、纯结构修复不读。

本卡依据 [分镜资料记录](storyboard-source.md) 中标注的范围重组为按需方法。品牌胶片、摄影机和模型能力未经本次实测；下文使用可观察目标，不把名称当作效果保证。

## 五层视觉方案

先确定整场或整片的稳定基线，再按剧情节点记录必要变化。五层都要做出选择，“无”也是明确选择；不要求在提示词里逐项列标签。

| 层 | 要决定什么 | 可观察的目标 |
|---|---|---|
| 1. 主色结构 | 高光、阴影、肤色、环境色之间的主要关系 | 哪些颜色占大面积，哪些只作局部信号；不止写“冷”“暖” |
| 2. 饱和度结构 | 全局克制程度与局部彩色重点 | 是近黑白、低饱和、自然饱和还是局部高饱和；肤色和剧情道具是否保留辨识度 |
| 3. 成像媒介／影调响应 | 高光、中间调、暗部怎样过渡 | 高光是否柔和滚降，中间调是否有分离，暗部是保留细节还是有意沉入；数字清洁或胶片式体量均写成结果 |
| 4. 颗粒 | 是否可见、粗细、是否随亮暗一致 | 无、几乎不可见、细颗粒或明确粗颗粒；不能掩盖脸、文字、动作接触点与背景结构 |
| 5. 高光溢出 | 发光边缘是否出现、强度与来源 | 无、轻微或明确签名；只围绕真实高亮区域，不让整幅图泛白 |

若用户给出具体胶片、摄影机或影片参照，可以保留名称作为审美沟通线索，同时把它翻译成上表中的可见目标。不能凭品牌名固定色温、颗粒或动态范围，也不能声称目标模型必然识别和实现。

全局方案要能解释相邻镜头为何属于同一场：稳定的主色结构、饱和度基线和影调响应优先。关键回忆、危机、发现或关系转折可以出现局部反差色，但必须有叙事理由和起止边界；不能为了“丰富”让每镜各自调色。用户已锁定色彩或媒介方向时，以锁定项为基线。

## 软化叠加按可读性诊断

以下六种都属于软化信号：**可见颗粒、高光溢出、物理雾／可见光束、扩散滤镜感、bloom、绘画式柔化**。“强效果尽量不超过两项”是排查叠加发糊的起点，不是每镜配额或默认阻断门槛。用户或当前项目明确采用数值上限时才按该锁定项验收；其余情况根据主体、空间和剧情证据是否可读决定保留或减弱。

- 大气透视若只表现距离带来的对比和色彩衰减、结构仍可辨，不计入软化信号；一旦抹掉结构，就按雾化问题处理。
- 强浅景深本身不在上述六项中，但会占用背景可读性。浅景深很强时，检查叠加雾与扩散是否进一步损伤信息；动作、多人关系或证据依赖背景时，优先恢复所需背景，而非按效果数量机械删减。
- 两种都未损伤信息也不代表必须保留。主体边缘、眼神、手部、文字、空间路线或相邻镜头连续性受损时继续减量。
- 已有风格需要更多强效果时，以用户锁定项和实际可读性为准，不因诊断提示产生额外审批。确与项目明确数值锁冲突时才交用户决定；不能用“轻微”的文字掩盖实际强度。

## 题材组合按签名放行

下表是选择起点，不是片种的物理事实。题材签名优先于通用“去饱和、去光晕”口号；具体事件和用户锁定项优先于题材标签。

| 方向 | 建议的五层组合 | 放行与防错 |
|---|---|---|
| 冷峻纪实／现实正剧 | 冷中性或受现场光影响的低彩主色；低至自然饱和；高光克制、中间调有分离；无或细颗粒；通常无溢出 | 允许自然暗部和不完美现场光；防止灰雾覆盖、广告级鲜艳和装饰性 flare |
| 科幻史诗／巨大空间 | 克制主色加少量功能色；低至适度饱和；高光有层级、尺度结构清楚；颗粒按媒介选择；溢出克制 | 有介质且有光源时放行定向体积光；真空用轮廓、遮挡和曝光分层，避免默认青橙滤镜 |
| 胶片诗意／浪漫 | 暖高光与环境冷暖关系；自然至适度饱和；柔和高光滚降；无或细颗粒；可选轻微暖溢出 | 放行有来源的柔和 flare、轻微光学瑕疵；防止均匀提亮、磨皮和整幅奶油雾 |
| 霓虹／高对比发光 | 深色基底加局部高彩；局部中高饱和；保持黑位和色光层次；颗粒克制；可把溢出作为一项强签名 | 放行彩色光污染与高光溢出；暗部应有层次或有意沉黑，不能整体抬灰 |
| 恐怖／惊悚 | 低彩主色加少量警示色；低饱和；允许大面积欠曝；颗粒按叙事媒介选择；通常无溢出 | 放行深黑和局部不可见，但剧情证据仍须可读；防止一刀切蓝绿色与为了“看清”平均补光 |
| 动作／战争／追逐 | 现场环境色为主，信号色清楚；自然或克制饱和；高光与深阴影保留冲击；颗粒可作一项签名；溢出仅在真实强光方向 | 放行运动中的曝光变化和有来源 flare；防止合成式边光、绿幕感和颗粒遮掉动作接触 |

风格化动画、绘画或广告若是用户明确方向，不用写实标准把它拉回现实摄影；仍检查内部光源逻辑、主体可读性、色彩连续和软化预算。题材表没有命中时，从故事与已有资产建立新组合，不硬套最近的一行。

## 质感锚点只在适用时写

- **所有镜头**：主体的光学细节清楚，高光有渐变，中间调与暗部不因灰雾粘在一起。整幅图不必同样锐利。
- **低调光／夜景**：暗部可以沉黑，但噪点、色块和脏灰不能吞掉必须读懂的内容。“纯净暗部”是可见目标，不等于全部提亮。
- **人物近景**：皮肤保留与距离相称的真实纹理、肤色变化和现场光响应；纯场景不写皮肤条款。
- **浅景深**：焦外随空间距离变化，建筑、家具、人物轮廓和遮挡边缘保持连贯；不出现涂抹、复制光斑或绘画笔触。
- **媒介感**：写“高光柔和滚降、细颗粒、暗部有密度”等可见结果。除非用户指定，不强塞摄影机或胶片型号。

这些描述能降低歧义，不能作为“画质保险”或模型能力证明。只有实际查看生成图或视频，才能确认是否实现。

## 防违和诊断与纠偏

| 可见问题 | 判断 | 修正 |
|---|---|---|
| 色调正确但画面仍廉价 | 五层中只有主色，影调、颗粒和溢出未作选择 | 补齐五层决策，优先修影调与主体可读性，不先堆滤镜 |
| 中间调发灰、暗部浮起 | 全局提亮、雾化或低对比覆盖了结构 | 恢复黑位与局部对比，保留必要暗部细节；不要用增饱和掩盖 |
| 高光惨白成硬边 | 曝光或后期锐化破坏过渡 | 恢复高光层次和柔和滚降，检查真实光源；非签名镜头移除 bloom／溢出 |
| 主体像贴在背景上 | 轮廓光无来源，或主体与背景色调完全脱节 | 回到现场光和材质响应，用一个主纵深机制重建分离 |
| 皮肤蜡亮、所有人物同一张皮 | 磨皮、统一高光或模板化纹理 | 还原现场光下的肤色起伏与距离相称的纹理，保留身份特征 |
| 背景像油画涂抹 | 浅景深与多种软化同时过强 | 找出实际破坏结构的效果，减弱对应叠加并恢复背景几何连贯 |
| 霓虹题材被通用禁令洗平 | 把高饱和、光溢出一概当缺陷 | 恢复局部彩色光和题材签名，同时保持暗部与光源依据 |
| 纪实题材像商业广告 | 全局鲜艳、均匀补光、每个物件都有高光 | 降低次要颜色和表面展示，按事件重排曝光与视觉中心 |
| 相邻镜头像不同作品 | 五层基线逐镜漂移 | 固定场景基线，只记录剧情节点造成的那一层变化及恢复点 |

先修造成问题的层，不用长负面词串同时禁掉所有颜色、光效和质感。涉及光源、材质或纵深结构时回读 [光源、纵深与材质](light-material.md)；涉及用户已确认画面的单项改动时沿用 [单变量修改](revision.md)。把采用后的具体选择写入当前作品，不输出卡名、内部分类或整张自检表。
