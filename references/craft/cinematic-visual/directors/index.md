# 导演检索：38 位

这里只收录原 ZY 包中有原文依据的 38 位，见 [来源](../sources.md)。分类用于选择方法，不把导演限定在一种题材，也不代表电影史全集或模型效果排名。

## 怎么读

- **已指定姓名：**在本文件中按中文名、英文全名或别名定位该行，只读取那张资料及 [四轴方法](../director-grammar.md)。可以用 `rg -n -i` 搜索姓名，无需通读名单或其他导演正文。
- **需要推荐：**先看下方创作目标导航，再到姓名表定位少量符合用户锁定项的候选，读取其正文后比较。表中短句只是检索摘要，不足以声称已采用。
- **需要比较：**读取被比较的导演，不把相近导演的交叉引用当作自动加载链。混合遵循四轴方法，先明确用户意图与主次。
- **未命中：**先核对全名、常见别名或拼写；仍无条目就说明未收录，不能假称读过。仅说“黑泽”“安德森”或 `Anderson` 不能唯一定位：结合上下文，仍不确定才问具体是哪位；禁止凭排列先后任选。
- **非导演任务：**不加载本索引。只说电影感、台词提到导演，或要求保持原风格，不自动加入导演方法。
