# 中文画面规格书（可选交付）

仅当用户需要逐镜摄影／美术细节、详细分镜规格书或单镜设计审阅时采用。普通分镜保持现有镜头表；图像工具提示词把相关设计翻译进实际支持的格式，不复制全套栏目。详细规格可先给一句导演意图和共用视觉方案，再逐镜填写所需块。

```text
镜头〈编号〉｜〈景别〉｜〈焦段或透视目标〉｜〈机位〉｜〈运动〉
【画面内容】当前事件、视觉中心、人物体位与持物；画内人物及画外同场人物。
【空间与机位】人物、镜头、观察目标、前景遮挡的位置；前后镜头继承什么。
【焦段与景深】空间压缩／透视目标、焦点与景深范围；若给毫米数说明所用等效口径，未定设备时不伪精确。
【摄影机行为】有意固定或一条连续路径；运动为何开始、停在哪里，是否发生真正切镜。
【光影】实际光源、空间方向、照到什么、阴影和遮挡；反打不重造光源。
【色彩与质感】共用方案的本镜执行：色彩、饱和度、媒介、颗粒、光晕及软化预算。
【纵深】主分离方法；前景／主体／背景需要读出的内容，前景没有依据就不添加。
【细节与限制】仅当前风险：清晰度、暗部、皮肤或焦外、形态、数量、禁止改动项。
【叙事语境】画外事件只用于解释当前人物神态与观看重点，静态图不声称产生声音。
【图像状态衔接】当前动作时刻、视线、持物与视觉接点；单图只表达一个状态。
```

这些字段可合并，纯环境不加皮肤栏目，深焦不硬写焦外光斑。色值是设计目标，不是成图像素实测；机身名、胶片品牌和术语不能替代可观察目标。每镜重复相同材质段没有新增控制意义时引用共用方案即可。

写法对照：

- 空泛：“电影感，85mm，压抑。”
- 可检查：“站在门外隔着门框看人物，脸和桌上未拆信件同时可读；人物停住拆信动作，窗光只照到手和信封，背景墙保留暗部结构。”焦段按构图与空间选，不先塞数字。
