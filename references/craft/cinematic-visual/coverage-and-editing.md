# CV-COVERAGE · 对白覆盖与剪辑连续性

用于多镜头对话、长台词、人脸接力、情绪重锤后的消化，以及轴线／视线／动作／声音衔接。只在命中这些问题时读取，不把本卡扩成完整分镜流程。知识吸收范围见[来源记录](storyboard-source.md)。

人物／非人物比例、连续镜头数、特写比例和技法次数按[受控分镜标准](../controlled-storyboard-standard.md)作按需诊断，只有当前项目明确采用才作为验收约束。镜头选择由剧情、观看信息和表演承担，不为比例增添空镜或随机小动作。

只读分析、单镜小改、对白换字或保留现状，不因命中本卡自动扩镜、出图或新建资产。用户锁定镜头、事件与平台格式优先；需要补镜时只补为满足已授权分镜和受控标准所必需的部分。

## 先决定这一镜必须让观众得到什么

每个镜头先回答四项，再选景别和机位：

1. 观众此刻必须知道的信息或感到的压力是什么？
2. 谁发起变化，谁承受变化？
3. 哪个可见动作、反应、物件状态或空间关系能证明变化？
4. 哪个在场、姿态、道具、视线、声音和情绪余波必须传给下一镜？

按证据选择画面主体：

| 当前职责 | 优先画面 | 不能被替代的情况 |
|---|---|---|
| 建立或更新关系 | 双人／多人关系镜头、可读站位的大景别 | 人物距离、阵营、进入／离开或权力关系发生变化 |
| 交代说话者的策略 | 说话者中近景、过肩或带动作的单人镜头 | 语气与身体行为共同构成信息 |
| 让观众读到话的后果 | 听者反应、沉默、距离变化 | 听者的理解、误解或决定改变下一步剧情 |
| 表达压抑或潜台词 | 手、脚、肩背、被操作的道具 | 局部动作比脸更准确，且动作来源与人物明确 |
| 提供事实或事件证据 | 物件、环境、光影、空间路径 | 该元素参与当前因果，不是装饰 |

不要把“人物镜头”和“非人物镜头”当轮换花样。人物脸、手、道具或环境中，谁最能承担当前信息就拍谁；需要建立关系、看清关键动作或看见决定性反应时，不能用随机空镜躲开人物。

## 对白覆盖：画面与声音分开设计

先按语义与行为划分对白节拍：提出、回避、追问、暴露、沉默、决定。切点落在信息转向、动作结果、听者反应、气息停顿或关系变化处，不能只按标点机械切镜。

每个切点分别记录：

- **画面主体**：说话者、听者、关系同框、局部动作、物件或环境；
- **声音归属**：谁在说，声音在画内还是画外，何时开始、何时结束；
- **在场余项**：未入画的人仍在同一空间时，保留其声音、手、肩、呼吸、视线压力或明确的画外位置；
- **入镜与出镜状态**：上一镜末尾动作和本镜开头能否直接连接。

长台词不自动触发切镜。先决定这句话的戏在说者、听者、具体行为还是尚未显露的信息；持续看听者也可以成立。需要转向物件、动作或环境时给出与台词的具体关系。台词跨到非说话者画面时，明确写“某角色台词画外延续”，保留声音归属和完整句子。

短对照：

- **弱**：A 连续解释失踪原因，镜头只在 A 的脸和 B 的脸之间来回切。
- **强**：A 开口时保留双方关系；说到“我没动过文件”时，切到他把撕裂的封条压在掌下，A 的声音画外延续；切回 B 时，B 已停止记笔记并抬眼。物件给出矛盾证据，听者反应给出后果。

## 非人物镜头必要性三问

每个物件、局部肢体、环境或光影镜头都必须逐项通过：

1. **它承载什么？** 必须指出新增的剧情信息、情绪证据、时间／空间变化或动作后果。
2. **为什么由它来拍？** 它应比人物脸更准确，或承担人物镜头无法同时交代的证据；“避免人脸重复”本身不足以成立。
3. **删掉会损失什么？** 如果删除后信息、情绪和衔接都不受影响，就删除；与相邻镜头重复则合并。

三问任何一项答不上来，不加入这个空镜。比例只是诊断参考时无需补足；项目明确采用比例且与必要性冲突时，先修现有覆盖，仍有冲突再报告。不擅自添加新剧情或无来源道具。

短对照：

- **不合格**：争执中切窗外树叶，只因“需要一个空镜”；删掉后没有任何损失。
- **合格**：争执围绕离职信展开，切到签名处被水滴洇开；上一镜人物握信的动作解释水滴来源，该镜同时证明犹豫与文件状态，下一镜接对方抽走信纸。

## 情绪重锤与反规则

先判断这是不是事实、关系或行动发生不可逆变化的重锤，而不是把大声、哭泣一律算重锤。常规表达可以收紧景别、靠近主体；当靠近只会重复表情时，改用反规则：拉远显示人物被空间吞没，固定镜头让真相停住，关系同框显示两人距离，或避开冲击本体只保留可见后果。

反规则必须写明两个理由：它反了哪条常规选择，以及观众因此多看见什么。不能为了“高级”而反着拍，也不能引用导演名代替画面设计。

情绪变化后按当前节奏判断观众是否需要消化。可以延续原镜头、留在听者脸上或让声音继续，不统一要求增加镜头。需要消化时从以下职责中选一项：

- **后果停留**：人物不说话，让呼吸、失焦的视线、未完成动作或身体重量变化继续；
- **听者承受**：保持沉默反应，显示这句话如何落到另一个人身上；
- **关系回看**：景别放松，重新看两人距离、空位或被改变的空间结构；
- **动作余波**：物件仍在晃动、液体停止、门声回落，必须来自刚发生的动作；
- **环境承压**：只有环境已经参与事件时才使用，例如警报声停下后的空走廊。

短对照：得知亲人失联后，连续推到哭脸再立刻抛出下一条秘密，会让两个重锤相互抵消。可以在真相落下时固定人物近景，随后切到双人远景：来报信者仍站在门口，接收者坐着没有起身，电话从手里慢慢垂下；空间、姿态和静默共同消化上一击。

## 多人连续性：切近不等于清空房间

多图叙事用当前图片任务的在场与姿态关系：`present_characters` 只因进入、离开、换空间或确认的时间跳跃而改变；`in_frame` 只说明本镜可见者。切成单人、反应或局部镜头时，其余同场人物仍记为 `offscreen_same_space`，并继承姿态、接触、持物和情绪余波。默认把这些关系写为自然语言，不为本卡读取其他制作手册或建立项目系统。

多人镜头按职责管理：能交代站位的大景别必须让人数、位置、遮挡和视觉中心可读；近景只聚焦主体，但不能写成其他人离场。关键听者在对白过程中保持行为存活：呼吸、视线、手部任务、距离或声音至少有一项延续，不能只在轮到说话时才“出现”。

## 镜头衔接六项核对

1. **轴线**：对话、对峙和方向性动作先建立轴线，正反打保持在同一侧。若叙事需要越轴，必须通过可见的机位跨越、中性机位或明确的空间重建让观众重新定位，并标出理由。
2. **视线**：记录谁从哪个位置看向哪个目标；下一镜给出的对象、高低与画面方向必须回应这条视线。不能脱离实际站位机械套“左看／右看”。
3. **动作**：上一镜的末态就是下一镜的初态。手的位置、身体支撑、接触点、道具归属、运动方向和残余运动一致；切镜不能把弯腰、搀扶或握持重置成中性站姿。
4. **画面变化**：同主体相邻镜头的机位、景别或焦段必须形成足够可读的变化，并服从[受控分镜标准](../controlled-storyboard-standard.md)；刻意跳切要写出叙事理由。
5. **运动与节奏**：运动接静止可以成为句号；速度或方向突变必须由新信息、撞击、情绪断裂等事件触发，不能只是换一种运镜。
6. **声音与画面桥**：换场、时间跳跃或大幅空间变化时，选择能保留因果的桥接方法；无需为顺滑而给每个切口加转场。

音桥要写成实际时间关系：下一场的门铃先进入，上一场画面仍停在未寄出的信上，随后才切到门外。视桥要指出延续元素与关系：上一镜手把文件推向画面右侧，下一镜从同方向接住文件；或上一镜圆形监视器切到下一场圆形车窗。若生成工具不能在单次生成中实现跨镜声音，仅在已授权分段制作及剪辑时这样完成；锁定一次出镜生成时改用可实现的镜头或声音衔接，不擅自改成外部剪辑，不能声称原始生成已实现。

硬切也可以成立，但必须承担明确作用，例如突然暴露新空间、制造时间断裂或截断人物话语；“没想到桥接”不是理由。

## 交付前只检查受影响段落

匹配转场另按下节的切点和不变项核对；普通对白覆盖不必附加转场。

- 每个镜头的主体是否对应本节拍最重要的信息；
- 每个非人物镜头是否通过三问，重复信息是否已合并；
- 长对白、人物／非人物、特写、留白和群像是否满足受控标准；
- 同场人物、姿态、道具、视线和情绪余波是否继承；
- 轴线、动作、声音和画面桥是否真正连接相邻两镜；
- 例子只作为设计对照，不当作已验证的模型能力或出图结果。

单图机位与观看职责按当前图片任务表达；连续观看和声音剪辑仅作分镜语法知识，不变成静态图执行要求，也不调用其他制作工作流；环境或物件所表达的故事证据可补读[环境与叙事证据](narrative-evidence.md)。

## 匹配转场的锚点与切点

仅用于已请求的变装、道具转换、遮镜或动作匹配切换。外部提示词方法候选，未实测；[来源与取舍](sources.md#帅帅导演-v4-定向吸收)独立于本页既有分镜来源。

1. **先选衔接依据。**从现有动作中选择握持点、手或肩位置、道具角度、人物轮廓、运动方向、摄影机方向、遮挡形状或构图位置。只取足以读懂本次切换的锚点，不固定要求三个，也不为了转场新增道具或动作。
2. **明确切点。**在衣料遮满、物体接近镜头、轮廓重合等实际可匹配节点切换，后一镜接续尚未完成的动作；除非明确设计停顿，不先停成摆拍再切。跳跃顶点只是可选节点，不意味着需要冻结画面。
3. **分开变化项和不变项。**变装允许服装变化，不自动允许换脸、换手或换道具。武器本身就是变形对象时可改变形状，但握持关系和出入方向仍应可读；用户锁定变化时刻时按该时刻执行。
4. **逐对核对，而非声称无缝。**比较切前末态和切后初态的持物手、握点、角度、尺度、运动趋势与机位所在侧。明显方向变化须有动作或新的空间证据；不要把角色自身左右与画面左右混为一谈。

例：用户只要求外套遮镜换装时，切前右手带衣料向画面右侧扫满镜头，切后仍由右手向画面右侧带离，只有指定服装改变。人物不必换场，也不必追加三个定势镜头。一次生成是否能实现该切换仍由当前平台及实际结果决定；不从写出转场推定可以外部剪辑、增加生成次数或费用。

一镜到底和明确禁切任务不调用匹配硬切模板；固定机位可以用主体或衣料遮挡完成已授权切换，无需额外运镜。用户要求刻意跳切或断裂时，保留其目的，不强迫所有切口顺滑。
