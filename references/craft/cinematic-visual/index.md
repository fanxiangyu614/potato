# 电影画面知识索引

这是独立图片技能的按需工艺索引，不是完整制作流程或默认预载包。先从用户当前要解决的问题选行，再读取该行的卡；正文不在本索引展开。按语义命中，不要求用户说出卡名。

## 按问题直达

| ID | 问题／检索词 | 读取 | 不触发的情况 |
|---|---|---|---|
| CV-LIGHT | 设计写实电影画面的光照与材质；塑料感、蜡皮、过锐、广告感、全画面一样亮、装饰性做旧 | [光源与材质](light-material.md) | 纯改对白、时长或颜色名称；“保持原光线”不是重新设计光线 |
| CV-LOOK | 光学柔化、五层色彩、局部撞色、景深层次、题材质感或滤镜叠加 | [色彩、纵深与质感](look-design.md) | 只改颜色名称不重做全片风格 |

| CV-ADAPT | 同一场景换平台、多模型版本、提示词转换时人物／动作／构图漂移 | [场景保真适配](scene-adaptation.md) | 单平台普通创作；不因提到模型名称就加载 |

| CV-WITNESS | 观众站在哪里、现场观察、真人抓拍、过度摆拍、补追与重新构图、远处目击、深焦调度、门边遮挡、直闪 | [观察位置与空间职责](witness-position.md)，只读命中的方法；临场响应为未实测候选 | 已锁定机位不重排；单图不加运镜；身份母版不以遮挡藏细节 |

| CV-COMPARE | 想看同题导演示例、看不懂导演拍法区别 | [同一事件的观看重点](director-comparison.md)，需要看图时才读对应图片 | 选择一位导演不默认读图；示例不作为模型能力或资产一致性证明 |

没有命中就继续当前图片任务。复合问题只补读确实需要的卡，不因读了索引而读完所有类别。已知具体卡路径时可直接读取；同一会话已读且仍适用的卡不重复加载。索引摘要只用于选择，不能代替卡片正文。

## 导演资料独立检索

原包 38 位导演均独立成卡；完整姓名、别名和创作目标只放在 [导演索引](directors/index.md)。非导演任务不读该索引。指定姓名时定位一行，比较／推荐时筛选需要的候选，不预读全部正文。未收录的导演不能冒充已入库；需要原作考据时另查可靠资料，不为一次创作自动扩库。

## 接回当前制作

这些工艺卡只辅助当前图片判断，不声称存在其他舱或给工具新增参数。当前画面的事件、参考职责、图片数量、实际模型适配与交付由主执行者负责；动画、广告、夸张动作等明确方向不被写实审美覆盖。

采用知识须落到当前作品中的机位、受光、材质响应、行为或保留／修改边界。读卡、列岗位和出现关键词都不等于采用。检查时核对这些决策是否服务于当前事件；不用把内部 ID、卡名或检查表写进用户的提示词。

维护或追溯来源时才读 [来源与吸收范围](sources.md)，普通创作不加载原包、示例图库、模型适配器或原包测试。
