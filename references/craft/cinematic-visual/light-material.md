# CV-LIGHT · 光源、纵深与材质真实性

用于当前作品需要重新设计写实光照、空间层次或材质受光，或结果出现无源亮边、全局均匀照亮、万能雾、背景涂抹、塑料／蜡质表面等问题时。只改颜色名称、保留原光线或已有合格方案时不读。

既有来源与改写见 [来源记录](sources.md)；本次补充来源及核实边界见 [分镜资料记录](storyboard-source.md)。这些方法用于设计与检查，不代表任何模型已经实测通过。

## 先区分物理关系与审美约定

物理关系负责让画面成立：主导亮部要能追溯到光源或合理反射，遮挡会改变受光，光经过空间会衰减；可见光束需要介质与有方向的光源，连续场景的固定光源不能随反打换到世界另一侧。环境反射和天空散射可以存在，不要求逐像素解释，但“环境光”“侧光”“电影光”不能代替对关键受光的说明。

审美约定负责让画面有选择：顶光是否压迫、暖光是否亲密、暗部保留多少、是否让人物成为最高亮度，取决于当前故事。下文“一镜明确一个主纵深机制”是土豆风暴的受控设计标准，不是自然界只能存在一种纵深现象。用户锁定的风格可改变审美选择，但不能把无来源的随机亮边冒充写实光照。

## 为当前事件建立光源关系

先写本镜必须读清的动作、表情或证据，再记录主导光源的四件事：

1. **来源锚点**：窗、灯具、火、屏幕、招牌、车灯、太阳、天空或场外但可推知的固定灯位。
2. **位置与方向**：光从世界中的哪一侧、何种高度到达主体；“侧光”只能描述方向，不能充当来源。
3. **覆盖与遮挡**：它能照到谁和什么，门框、人体、家具或地形挡住哪里。
4. **衰减与落点**：近源区域、远处、阴影交界和反射面怎样变化；避免所有脸、墙与道具同亮。

次光、反射光和实景杂光只写对叙事可读性有影响的部分。需要多人同时完成动作或让观众读懂证据链时，可保留多个清楚区域；不要机械压暗到只剩一张脸。夜景和低调光也必须看得见规定动作、接触点与必要表情，“黑得看不见”不能代替氛围。

连续动作内继承世界中的光源位置、开关状态、天气和时段。换到反打机位后，镜面反光和可见亮面可以随观察角度变化，固定窗灯的位置不能跟着摄影机翻面。发生开灯、车灯扫过、火焰变强、云层遮日或明确时间跳跃时，才按可见事件更新受光；时间跳跃后重新判断方向，不沿用旧场的表面效果。

## 纵深不是浅景深

景深决定焦点范围，纵深决定前中后景如何被读成空间。每个需要空间层次的镜头明确 **一个主纵深机制**；其他自然存在的线索可以保留，但不要把雾、虚化、轮廓光和前景遮挡全部写成同等强度的“电影感”装饰。

| 主机制 | 适用条件 | 写法与检查 |
|---|---|---|
| 光／曝光分离 | 室内、夜景或主体与背景受光不同 | 用有来源的受光和对比区分层次；不能凭空给人物补轮廓光 |
| 距离造成的对比与色彩衰减 | 外景或大尺度远景 | 远处可降低对比、轻微去饱和；建筑、地形和轮廓仍应连贯可辨 |
| 遮挡／尺度递退 | 场景已有门框、家具、建筑、地形或人群 | 用真实重叠、大小递减和路线关系形成层次，不为做前景临时塞无关道具 |

强浅景深可以聚焦人物或细节，深景深可以保留环境与多人关系，焦点转换可以引导一次明确的发现。它们都不能替代上述空间关系。身份母版、道具母版和需要读取多人动作的参考图，以结构可辨为先，不用暗部或虚化藏掉必须复用的信息。

### 雾、烟、尘与可见光束双检

写体积雾、丁达尔光束或可见光柱前，必须同时满足：

- 场景中确有雾、烟、尘、蒸汽、雨雾、雪或其他可见介质；
- 存在可定位、带方向并会衰减的光源。

满足时描述介质如何捕捉那束光、密度怎样不均，并保留主体剪影和背景结构。任一条件不满足就删除体积光语言，改用主纵深机制。真空环境不加全局大气雾；若故事明确有尾气、泄漏气体或碎片，只处理该局部介质。

## 材质跟随受光和事件

玻璃、湿布、皮肤、纸张、漆面和金属不会共享一种高光。按当前角度与光源分别说明透射、漫反射、吸光、粗糙反射或局部镜面高光。磨损跟随接触和使用位置，水迹跟随来路与重力，损伤跟随事件；没有成因不增加脏污。真实不等于灰暗、贫旧或低清，干净新物件和明亮空间同样可以写实。

人物近景需要保留与距离相称的皮肤纹理、肤色起伏和自然表情，同时让高光方向服从现场光。不要给所有人复制同一种毛孔、瑕疵或“次表面散射”词串。浅景深时，背景几何、光点与遮挡边缘仍应连贯，不能变成涂抹或绘画笔触。

## 从可见失败做最小修正

| 观察到的问题 | 优先检查 | 最小修正 |
|---|---|---|
| 人物两侧都有漂亮亮边，却找不到灯 | 来源锚点、遮挡和反射面 | 删掉无依据亮边；从现有窗、灯或反射面重建一侧受光关系 |
| 反打后窗光换边、阴影方向跳变 | 世界光源位置是否随摄影机翻转 | 固定窗灯方位，只更新观察角度下的可见面与镜面反光 |
| 背景像一团雾或被涂抹 | 是否把雾、虚化当作纵深 | 选一个主纵深机制，恢复背景结构；无介质时删除体积雾 |
| 光束遍布画面但空气清洁 | 介质与具名光源是否同时存在 | 缺任一条件就移除光束，用曝光分离、遮挡或尺度表达空间 |
| 皮肤像蜡、纸和衣料都发亮 | 是否统一磨皮、锐化或镜面高光 | 分开皮肤、纸、布与金属响应，保留原身份、构图和光源 |
| 夜景“有气氛”但看不清关键动作 | 关键证据是否落在可读范围 | 只恢复手部、接触点、表情或路径的可见条件，不整体抬亮背景 |
| 旧屋像做旧展台 | 污渍、磨损是否有使用或剧情成因 | 删除无因纹理，只保留事件与生活真正留下的痕迹 |
| 像广告陈列，所有物件都抢眼 | 曝光、锐度、占幅是否平均分配 | 按当前事件重排可读性，让次要物件自然退后 |

例如夜班人员在工作台核对标签：台灯照清指尖和标签，棉袖吸光，金属夹只在朝向灯的一小段出现高光，后方架子随距离变暗。这里的设计关系比“电影感、8K、胶片颗粒、塑料感禁用”更可执行。

视频中核对受光变化是否跟随可见过程，相邻镜头继承固定光源以及衣物湿度、损伤和材质状态。需要调整整体观感时按需读取 [视觉方案与防违和](look-design.md)；空间与可见性风险仍由 [空间预检](../spatial-shootability-preflight.md) 处理。

删掉品牌、分辨率和泛化“高级感”后，描述仍须留下明确的光源、空间与材质关系。把需要的关系写进当前交付，不输出整套内部检查表。
