# 分镜检查要点

主执行者依据图片目标与风险安排自查，复杂身份、空间或多人关系可采用独立观察或不同验证路径复核。以下是检查内容，不另设岗位数量或记录模板；生成及修复始终服从当前用户授权与实际工具限制。局部修改只复查受影响的镜头及前后衔接。

- 镜头目的与观众获得的信息是否明确，是否服务当前故事。
- 一个镜号是否包含隐含的第二机位；切镜、运动和时长能否容纳所写动作。
- 按 [受控分镜标准](controlled-storyboard-standard.md) 核对批准节拍覆盖、每镜观看目的及可见证据；新增动作、道具或事件有依据。历史比例和次数只在用户／项目明确采用或具体问题需要诊断时读取[相关附录](controlled-storyboard-appendix.md)，不默认完整读卡或统计。
- 身份、在场、朝向、持物手、道具状态与相邻镜头是否连续。
- 复核准备提交的实际正文、有序参考与参数：看杯到手部动作保留视线和已有动作，画外说话看听者保留声画归属，横移揭示保留起点遮挡、路径和终点主体。同义表达可通过；丢主体、改动作、声画错配或无依据插镜须指出。复核当前真实输入版本，不将已过期的文字检查当作本版验收。
- 实际查看所需参考图再判断图像；缺失素材时明确未验项，继续不依赖该素材的工作。

用户指出错误或自查发现问题时，由主模型核对依据、修复授权范围内的缺陷并复验受影响内容。不能把可修问题留成未审核候选，也不能用尺寸、编号或格式通过代替内容判断。

## 提示词压缩检查

仅在交付可复制提示词、压缩既有稿或适配字符上限时使用；不要求普通问答读取整份分镜检查。本节为[帅帅导演 v4](cinematic-visual/sources.md#帅帅导演-v4-定向吸收)的文本方法候选，不是“越短生成越好”的实测结论。

- 先保住用户锁定的身份与参考映射、时长、动作顺序、机位、方向、持物、转场、对白原文、声音及结尾；当前平台必需字段也不能删除。
- 对拟删除句子问：删掉是否改变可见画面、可听声音、必要状态或生成执行关系？只有均不改变时，才删重复修饰、同义形容词、教学解释和创作理由。不把导演解释写进模型要执行的正文。
- 同一次生成中的全局设定集中写一次，各镜头写变化和必要继承。不同片段将被分别提交生成时，每段仍保留独立执行所需的身份与状态，不用“同上”假定模型能读到前段。
- 用户未要求缩字时，不为了简短删动机、关键接触或连续性证据。纯图片只描述当前可见状态，不塞整段动作与音轨。
- 有字符上限时按约定口径计算完整交付，再对照锁定项复验；全部必要内容仍超限时说明具体冲突，不截断对白或暗改时长。文字保真检查不等于成片验证。
