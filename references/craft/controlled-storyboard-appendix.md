# 受控分镜历史参照附录

仅在用户／绑定项目明确采用数值约束，或需要定位具体覆盖问题时，读取对应条目；不默认全文读取或完整统计。未采用的参照值不是验收门槛。回到[受控分镜关键原则](controlled-storyboard-standard.md)。来源见[吸收记录](cinematic-visual/storyboard-source.md)。

## 先定统计单位

- 一个镜头是一次连续观看；切镜才新计数，同镜推近、拉焦不重复算。镜头号、独立生成片段、参考图面板不是同一单位。六格关系板不直接计作六个成片镜头。
- 全片指标只对本次设计的完整作品统计；出镜的一次完整生成以其本次镜头序列统计，不扩算成整个系列。只提供一场或局部时，报告当前范围，缺全片不能称全片通过。单场、对话段的上限单独计。
- 比例按镜头数而非秒数算。上限镜头数取 floor(比例×分母)，下限取 ceil；不四舍五入，不以时长稀释镜头数。分母为零则不适用；上下限没有可行整数时报告当前镜头数下无法同时满足，不扩镜凑数。
- 人物镜头：以完整人物或面部表演／人物关系为视觉中心；非人物镜头：以道具、环境、光影或局部肢体状态为中心。人物在背景或有画外人声不自动变为人物镜头。混合镜按主视觉任务归一类，不能双计、改标签凑比。
- 人物特写只算人脸特写／大特写；物件与手部特写不计入人物特写分子。固定镜头比例按实际摄影机行为计，不以“呼吸式微推”改名掩盖无叙事作用的固定。
- 长台词非人物覆盖的分母：同一长台词持续期间，为承接该声音而切入的新画面总数；排除开头说话者镜头与台词结束后的反应镜头。分子为这些承接画面中的非人物镜头数，逐段核对，不以全片数量代替。

## 历史参照值：仅按需诊断，明确采用后才计数验收

| 项目 | 执行标准 | 范围与条件 |
|---|---|---|
| 固定镜头 | ≤30%；不连续3个固定 | 完整镜头序列；明确固定／一镜到底的用户锁定优先 |
| 平视 | 不连续3个平视；至少有一次仰拍与一次俯拍 | 完整多镜头序列；角度能实现且服务事件，不加无意义倾斜 |
| 焦段／机位／运镜多样性 | 至少4种焦段、4种机位角度、6种运镜 | 源文允许空间不足时不凑种类；镜头数或已锁拍法无法容纳时列明限制，不造新镜 |
| 景别与景深 | 不连续3个近景；完整镜头组包含大景别、中景、特写；景深策略有变化 | 空间及用户构图优先；不把全片条件套单镜。大景别指本场可实现的空间交代 |
| 对话开场与关系 | 开场中景或全景；至少一个双人同框关系镜头；不全程固定 | 明确要求其他开场／固定拍法时按锁定；关系镜不等于额外生成关系板 |
| 同主体相邻切镜 | 机位角度差≥30°，或焦段形成可读差异 | 源文同时允许焦段差异；刻意跳切按明确叙事理由记录例外，不能声称实测角度 |
| 相邻景别跨度 | 不超过3级；超过须有过渡或明确叙事例外 | 按大远景→远景→全景→中景→近景→特写→大特写排序，跨越的级差计数；先改可变景别，不默认加镜 |
| 对话人物特写 | ≤该对话段镜头数40% | 以人物特写定义计；必要反应与用户锁定不可被插镜替换 |
| 人物连续出现 | 不连续4个人物镜头，第4个应以必要非人物镜头或重新组织覆盖解决 | 不把全身改名“环境镜头”绕过；无必要插镜时走冲突处理 |
| 非人物占比 | 完整作品历史参照30%—50%；段落细分见下表 | 每镜通过必要性检查；不能增加原戏无依据的杯子、天气或动作凑数 |
| 长台词覆盖 | 有足够长度容纳切换的长台词安排切镜；其切镜承接画面中非人物≥50% | 原文“两三句”为识别信号，实际可说时长与动作容量先核对；不拆字词凑切点、不删台词 |
| 群像 | ≥3人场景中，承担站位交代且画内≥2人的群像镜头≥场景镜头数40% | 不只在大景别内算分母；镜内是否可见按实际视域，不强迫全部在场人塞进每个中景 |
| 情绪重锤后 | 至少一个消化情绪的留白镜头 | 可为人物反应或原有持续观看；不必空镜；片尾可在末镜落入停留，不强造片尾后续镜 |
| 反规则机会 | 每场识别至少1个，通常1—2个反常规拍法的机会 | 采用须解释观看效果；无合适机会如实注明，不为“反规则”标签改戏 |
| 局部反差色 | ≤总镜头数15% | 同一全局色调内短暂反差；用户已定多色段落结构优先；不要求必须出现反差色 |
| 软化预算 | 同镜最多2种全开强软化，其余减弱或省略 | 颗粒、光晕、雾、扩散等联合检查，详见[色彩与质感](cinematic-visual/look-design.md)；不是软件参数 |

下面的段落比例同样是可选参照，不是默认应达到的范围。明确采用时不与全片分母混算；没有叙事用途的空镜或道具特写不加入序列。

| 段落 | 非人物比例 |
|---|---|
| 长对话（超过5个来回） | 35%—50% |
| 中等对话（3—5个来回） | 30%—45% |
| 短对话（1—2个来回） | 20%—40% |
| 情绪爆点对话 | 25%—45% |
| 内敛压抑戏 | 35%—50% |
| 纯动作、无对话 | 15%—35% |

## 重技法的历史次数参照

| 技法 | 全片上限 | 单场上限 | 需要的叙事依据 |
|---|---:|---:|---|
| 滑动变焦 | 1 | 1 | 认知或空间感崩塌 |
| 环绕／弧形 | 3 | 1 | 关系揭示、主观凝固或主体强调 |
| 人体固定摄影机视角（Snorricam） | 1 | 1 | 主观失衡或恐慌 |
| 长镜头 | 2 | 1 | 连续行动、沉浸或情绪累积 |
| 鱼眼 | 2 | 1 | 明确的主观畸变 |
| 荷兰角 | 4 | 1 | 空间或心理失衡 |
| 升降 | 2 | 1 | 揭示空间或关系，具备运动余量 |
| 摇臂 | 2 | 1 | 连续空间路径有意义且可实现 |
| 人物主观视角 | 3 | 1 | 发现、感知或主观体验 |

使用前核对叙事目的、观看变化和运动是否可实现。只有项目明确采用次数上限才计算剩余额度，不默认要求用齐或限次数。长镜头按持续观看的叙事功能识别，不把每条几秒钟的连续镜头都算“长镜头”。
