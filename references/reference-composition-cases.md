# 参考图干扰、尺度与数量案例

按当前故障查行。下表区分来源文档自述与本次整理的改写例；未读取原始成图与完整实验记录，不把gid当成已核实成功率。案例用于提出检查与修正方向，不保证提示词生效，不追加重试预算。

| 问题与反例 | 正向处理／相对成功记录 | 实际检查 |
|---|---|---|
| 参考风格冲突：来源自述gid57—64混用真人与卡通参考，出现卡通化、脸融合及无关气泡 | 来源称gid62相对成功，减弱构图参考影响并保留风格说明；这里采用“分清身份／构图／风格职责，移除冲突职责”的方法，不把保留某词写成定律 | 用户若要混搭，保留目标混搭；先查是否把仅借姿态的图当作风格真源，不能一概删卡通图 |
| 半身角色参考抢走远距离构图：来源P2.4案例自述，隔屋对峙变贴身近景 | 改写例：角色图仅供脸和服装，站位图仅供体位与距离；正文明确中间隔物及人物远近 | 不让站位图覆盖用户机位；若要求越肩，保留越肩，用前景肩的位置与背景尺度表达真实距离 |
| “飞10米”缺少画面尺度证据 | 改写例：人物脚下可见楼顶，脚与屋顶间有连续空气层，以仰视及建筑比例表达悬空；仅在机位允许时采用 | 不是强行改成仰拍；已定俯拍时以地面缩小、建筑对照和遮挡关系表达，不宣称像素证明精确米数 |
| 巨物变成普通大小，或龙形变成无特征长管 | 来源图型01／15／16／17与问心形态锁提供局部巨物、全貌设定、比例参照和“龙非虫”写法；本次整理：叙事局部镜用环境作尺，设定页用全貌＋同基准面参照 | 尺度与物种辨识分别检查；全貌与“不准全身入画”不能同时套用；保留项目真正的头部、肢体与轮廓特征 |
| 数量错误：来源总则称多格数量不稳，但图型10又把同场多机位列为可用方案 | 正向方案是逐格明确内容，实际数格与数主体；数量不准时在授权范围内拆成单图，必要时确定性排版 | 不宣称多格必失败或必成功；排版能保证面板数，不能修正单图内肢体、道具数量与身份 |
| 小字／色块错排：来源增补§10曾把gid72、gid140列为反例，后自述复检改为成功 | 保留这条纠正作为证据边界示例：以文字设计规格记录目标值，实际图片另查视觉与文字是否符合 | 不把prompt中的HEX当成成图像素达标证据；精确文字可另行排版，当前源文自我纠正也不等于本地看图验证 |

判断顺序按当前问题选择：输入参考是否冲突、空间与形态是否明确、数量／比例是否实际可读。修改前复用已有资产与已确认结论，修正后检查受影响区域与镜头衔接。用户只要提示词时不自动调用生成或后期工具。
