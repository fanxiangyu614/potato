# 图片资产与跨舱协作

仅在项目图片资产或其他舱调用图片服务时读。一次性单图不建项目、不建第二套状态库。图片服务不反向加载源舱入口，不递归调用土豆风暴；源舱交付需要平台规则时由源舱自己表达。

## 先复用，再补缺

先用项目现有索引按人物／地点／道具 ID 和用途查找，读取命中条目及实际文件；没有索引时仅搜索相关目录。旧标签和文件名不能证明仍可用，核对本次版本、身份、妆造与剧情状态。只查看候选中实际需要的图片，不默认做全库缩略图、全库哈希或重扫全部资产。

已有图片满足需求就直接返回引用；设计已确定但缺图时按原设计生产，禁止重新随机美术方向。仅缺服装、状态或机位时复用有效身份与场景参考，只补缺项，不重复做全套人设。待审核、失败、弃用图不能冒充锁定参考；检索不到或无法读取须说明缺口。

## 最小调用信息

在当前上下文用短文字表达即可，不强制 JSON、事务文件或完整表格。已有信息直接复用：

- 要交什么：图片／图片提示词／修改／分析，资产用途、相关角色或镜头 ID、必要数量和画幅。
- 依据：本次实际参考图路径或可用会话引用，每图负责身份、服装、空间、构图、动作状态还是风格；相关锁定设定与来源位置。
- 改动范围：必须保留项、允许改变项；状态图才传当前可见瞬间及受影响前后状态，不传完整剧本。
- 执行边界：既有生成数量／预算、已有新图生成、整图修复与局部修复各自累计次数、保存位置，以及本次是否已有正式采用授权。

缺少普通偏好使用合理默认值并简述；缺少目标图、身份依据或相互冲突的锁定项会影响交付时才请求补充。纯虚构、授权新设计可自行补全，不能把设计默认值说成项目已有事实。

提交前把本图要求对应到实际工具输入：指定人物对应身份图，锁定空间／道具对应原片或设计，保留拍摄条件对应原始摄影基准；审阅时同样提供这些依据，不能只给人设。每张参考写明负责什么、不继承什么（例如原游客身份不继承，现场光源与成像关系保留）。核对实际上传／工具参数，提示词里提到参考不等于已传入。仅供验收的范例不自动上传给生成模型。正式制作使用[质量卡](storyboard-image-quality.md#正式制作的最小记录)中的现有记录与实际输入核对方法；一次性任务直接核对当前调用即可。

## 按资产用途取规格

| 用途 | 本次应锁定与交付 |
|---|---|
| 视觉人设／身份参考 | 面部辨识、年龄感、体型轮廓与必要特征；剧情性格仅转为可见设计。按需求给身份图，不自动扩成头像三视图、Hero Bust、服装全套 |
| 妆造／服装状态 | 基于有效身份参考，明确妆发、服装层次、材质、配饰及剧情时点；污损、湿度、伤痕按状态分别标识，不污染基础身份图 |
| 场景／道具 | 场景基底与具体机位分开，锁定门窗、尺度、光源与叙事道具位置；道具锁定形状、尺寸关系、材质和必要状态，避免每镜重做母资产 |
| 首帧／尾帧／动作状态图 | 只设计该帧能看见的瞬间；人物在场、持物手、姿态、视线、遮挡与动作端点来自源镜头。先检查相邻衔接，不为凑图增加镜头或动作 |
| 风格参考 | 明确仅负责光照、色彩、材质或构图中的哪些项，不借风格图替换身份或剧情事实 |

源舱已给规格时直接沿用。确需短剧专用资产格式且未传来时，只读 [visual-craft.md](craft/visual-craft.md) 的相关段落，不读整舱。状态图遵守共享 [动作与端点规则](craft/action-endpoint-continuity.md) 的受影响部分；复杂空间才读 [空间预检](craft/spatial-shootability-preflight.md)。普通人设与妆造不加载动作资料。

## 批量与返回

按身份、场景依赖排序：复用有效母资产，再做需要的妆造和镜头状态。未锁定且会影响整批的设计先用必要代表图验证再扩展；已有锁定图不重做样张。小批只用于规划当次必要镜头，实际执行遵守[逐张制作与六项验收](storyboard-image-quality.md)：每张完成生成、检查、额度内修复及复检及采用或废弃后，才做下一张，不并行出待检图、不整批生成后再返修。调用授权以图片舱入口为准，修复累计上限按所引质量卡执行，不在资产交接中另设额度。不合格只暂停依赖它的后续图片，当前图处置完成后其他独立任务可继续；下游只能引用合格图。图片数量由任务决定，不设套餐，不默认一次生成全片首尾帧。

返回实际成果路径／会话图引用（或完整所需提示词）、资产用途和相关 ID、检查结论与尚存偏差；只有有返工时附实际调用／修补次数与参考来源。源舱据此继续分镜或平台绑定，不再复制长提示词与整套参考内容，不把未检查的图片标为可用。

用户要求保存时按统一[项目文件收纳](standalone-operations.md)沿用目录和索引字段；新增项目只记录需要的资产 ID、用途／状态、路径、来源及检查结论。生成重试跨批或跨会话时保留实际次数，不新建通用数据库或强制改造项目 schema。已有采用授权则源项目负责人按 [正式项目更新](standalone-operations.md) 移入现用位置、同步引用并处理被替代候选；候选保存不等于正式采用。`project_writer` 不变，图片服务不能自行覆盖正式资产绑定。
