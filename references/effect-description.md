# 特效描述与纠偏

用于已有特效设定的表达与修正，不替项目决定能力、胜负、人物情绪或整体风格。先用一句话分清颜色、形态、材质，再说明作用位置与遮挡；无需强制新建色卡或在每段重复全部颜色。

## 描述骨架

```text
〈谁的何种效果〉：〈颜色与饱和度〉，形成〈轮廓、运动方向与占画面范围〉；
呈〈气态／液态／硬结晶等材质〉，〈透光、密度、表面和边缘〉；
局限于〈区域〉，与〈人物／环境〉的前后关系为〈关系〉，保留〈必须可见的叙事证据〉。
```

区分同场两种效果时，颜色之外再选一个形态或材质差异；仅在允许调整的维度设计，不擅改锁定色。HEX 可保存为设计规格，不能保证生成像素严格等于该值。

## 改写示例（非本地出图验证）

| 模糊表达／可见失败 | 更具体的表达 | 检查点 |
|---|---|---|
| “强大的风”，结果细弱或实心 | 青蓝半透明粒子流形成宽幅旋卷，流束之间留出可见天空的间隙；气势来自覆盖范围与运动弧线 | 覆盖够大、仍有空隙，不变成玻璃管或水绳 |
| 冰与风同色同质 | 沿用项目色：风为软流动粒子，冰为硬质结晶面与锐利断口 | 即便接近色，也能依形态辨认；若冰是实墙就不强迫它通透 |
| 风中粒子变成全图噪点 | 粒子仅分布在风流内，脸、衣物与背景保留既定纹理 | 噪点未覆盖全图；保留用户指定的真实胶片颗粒 |
| 特效放大后遮住表演 | 保持效果规模，将主流束安排在〈已授权区域〉，让〈眼睛／持物手等〉仍可读 | 没改动作、机位或叙事中心；不默认所有特效都在身后 |
| 发光变成塑料霓虹管 | 〈介质〉内部局部散射光，边缘断续、粗细不一，保留〈具体材质〉 | 不用“高级感”代替材质；金属或霓虹本就是设计时不排除它 |

英文短语仅供目标模型需要时选用：`translucent`、`open gaps`、`soft flowing particles`、`hard crystalline edges`。不是必用咒语，不固定中英文分工。

修正前确认问题是颜色、形态、密度、位置还是整体风格；只动允许项。重跑与修复沿用图片舱额度，提示词中的“保持不变”不等于已验证保真。
