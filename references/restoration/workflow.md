# 多面脏图修复模块

多面脏图修复器。先解析结构与空间，再为实际可见区域分配材质修复策略，组合原有模块与强度档位，生成中文图生图提示词或直接完成图像编辑。

修复遵循 [模型适配与画质判断](../../SKILL.md#模型适配与画质判断)：以用户目标、当前模型和原图实际问题为依据，不自动加入固定防伪影清单。原文预设可照录或按当前任务适配，不要求追加通用基础正文。

## 模型专用预设

已选 Google Nano Banana 2／2.1 进行真实人像高清或质感修复（含面部油脏、灰脏、头发黏腻），或索取专用提示词时，读取 [Nano Banana 2／2.1 人像修复完整基底](nano-banana-2-portrait.md)。命中时保留完整用户原文，再补具体缺陷和必要风格保留项，不用下方通用五模块或局部弱化稿替代。只索取提示词时不生图；实际编辑沿用已确认入口、查看原图并复检，遵守既有次数上限。

## 核心原则

**只修纹理，不改主体。** 优化画面中各类材质的纹理、材质反射、边缘质量与画面洁净度，不进行重新设计。不改脸、不改身体、不改服装、不改构图、不改颜色、不改灯光、不改背景、不裁切、不扩图。

**原图约束结构，物理材质指导纹理。** 不把原图的涂抹、塑料感、噪点和压缩损伤当成必须复制的材质；在损坏区域重生符合原材质、原光影和原透视的微观肌理。“重构/复刻”默认指忠实保留内容的材质重构，不是重设计。无法辨认的身份细节、文字、结构、材质或真实颜色标为“无法确定”，不把补绘说成原始细节的精确恢复。

**交付按用户意图。** 用户只要提示词时输出提示词，不调用生图；用户要求修图时直接编辑。用户明确要求改变背景、颜色或灯光时，只对指定项覆盖默认保留规则。全局图生图表示整张图作为参考，不表示全图都要重绘。

## 执行边界

审阅或维护本模块时只处理规则文件，不启动修图。已给图片且要求修图时，先遵循[修图模型选择与适配](../../WORKFLOW.md#修图模型选择与适配)确认本轮模型；确认后诊断、选档、构建指令和编辑连续完成，不再询问是否开始或是否采用自动档位。除此之外，仅在缺少可引用的目标图片、存在无法兼容的明确要求或动作超出授权时询问；普通材质不确定时保守保留并继续。

与其他模块 联用时，以用户要的最终效果分工：本模块 负责缺陷清理，MJ 优化负责已要求的光影美学，内部风格探索模块只提供已要求的风格方向。用户明确要求的风格化可覆盖对应保留项；没有风格化要求时不因同时提及其他模块 而自动改风格。优先合并成一次编辑，不按模块数量重复生成；只有用户要求中间成果或独立版本时才分开。

## 工作流

### 第一步：修复前图片诊断（必做）

先查看当前待修图片，在生成提示词或调用图像编辑前完成诊断，不直接套用清理词。记录：
- 问题位置与可见表现：噪点、色噪、脏斑、压缩伪影、光晕、异常高频纹理、涂抹或塑料感；说明局部还是大面积，以及真实材质是否仍可辨认。
- 区分缺陷与保留项：真实纹理、做旧、事故损伤、玻璃裂纹、碎片、阴影与合理颗粒不能统称为脏污。无法确定的内容标为“无法确定”，保守保留。
- 给出强／中／弱档、选择理由、实际处理区域与必须保留的内容。人物位置等形体问题另行识别，不能靠提高去噪档位解决。

修复前向用户简短说明，例如：“问题：背景有少量色噪，主体纹理完整；采用弱档，清理背景色噪，保留人物和原光影。”随后直接继续，不将分析变成确认或审批步骤。只要求分析时止于分析；只要提示词时不生图；要求修图时继续执行。用户明确指定档位时仍分析图片，但遵守该档，不自行升级。

### 第二步：全场景结构解析与模块选择

复用第一步已查看的图片和诊断，结合可辨认证据补齐以下信息；用户只修局部时仍理解空间关系，但只处理指定区域：
- **类别与风格**：人像、产品静物、自然风景、建筑空间等，并区分摄影、老照片与动漫插画。
- **主体结构**：身份、骨架、姿态、形状、轮廓、数量、服装配饰，以及产品按键、接口、刻印、建筑飞檐等特殊结构。
- **场景与空间**：背景元素、前后景、透视、遮挡、机位、景深、环境和画幅比例。
- **保留与损伤**：分清真实纹理、自然阴影、历史痕迹与脏污伪影，记录无法确定的部分。真实杂物属于场景内容，不能仅因“背景脏乱”而自动删除。
- **问题定位**：把“脏/糊”写成可见缺陷及其位置，例如背景随机斑点、暗部色块、边缘光晕或主体涂抹。先区分去噪、材质重建与形体修改；形体修改仅在用户明确要求时执行。

复杂修复可根据已完成的观察选取需要的材质模块；普通任务无需先加载模块组合：

| 图片类型 | 识别特征 | 默认模块组合 |
|---|---|---|
| **人像/写真/自拍** | 人脸为主体，面部占比>20% | `portrait` + `fashion`（有服装时）+ `special-material`（有珠宝/眼镜/金属配饰时） |
| **电商产品/静物** | 商品为主体，纯色/简洁背景，棚拍感 | `product` + `special-material`（按材质：玻璃/金属/宝石等） |
| **风景/建筑/街景/室内** | 无突出人脸，以环境空间为主体 | `scene` |
| **老照片/划痕/噪点严重** | 可见划痕、霉斑、褪色、黄变、高ISO噪点、胶片老化 | `old-photo` + 对应内容模块（人像/场景等） |
| **动漫/插画/漫画** | 二次元风格、赛璐璐上色、线条稿 | `anime` |
| **美食** | 食物为主体 | `special-material`（food）+ `scene`（有背景时） |
| **混合/多主体** | 同时包含多类元素 | 以最突出主体选主模块，叠加可见元素的辅助模块 |

**模块使用**：仅在需要相关材质指导时读取，不要求主模块或固定组合。模块中的保留、清理与增强词是候选描述，不整段照搬。例如仅调整人像曝光，不因此加载珠宝、服装或去纹理模板。

**用户覆盖**：用户明确指定修复对象（如"只修皮肤"、"修一下这个产品"）时，以用户指定为准，仅加载对应模块。

### 第三步：依据诊断选择强／中／弱档

需要纹理清理程度参考时再读取 `intensity-presets.json`，按实际问题选取适度处理；单纯光影、颜色或局部内容编辑无需选择去噪档位：

| 档位 | 适用证据 | 操作 |
|---|---|---|
| 弱（light） | 少量噪点、轻微脏点或压缩伪影，材质与细节完整 | 轻微清理，保留微细节、对比度与颜色，不重建纹理 |
| 中（standard） | 明显噪点、色噪、脏斑、局部不稳定纹理，真实材质大部分可辨认 | 中等清理，稳定纹理和过渡，仅必要处局部重建 |
| 强（deep） | 密集高频脏纹、大面积异常微纹理、严重涂抹、塑料感或纹理损伤 | 强力清除受损区域伪影，按对应物理材质重建，保护完整区域 |

对外统一称强／中／弱；配置键保留 deep／standard／light，兼容旧称深度／标准／轻度。老照片、夜景、事故场景等类别本身不决定强度；没有明显问题时说明无需修复，不强行强修。混合程度以主要待修问题确定主档，正文明确较干净区域轻处理或保护；默认仍整图作为参考直接编辑，不强制裁切、蒙版或合成。

档位表示提示词策略，不是已设置的工具数值参数，也不保证强档一次成功。
### 第四步：加载配置文件

已有明确目标或模型专用方案时直接构建提示词；只有缺少相关指导时才读取需要的配置：
1. `global-rules.json` — 通用保留与材质参考，按用户改动范围取适用项，不把其负面词全部加入提示词。
2. 第二步实际需要的材质模块 — `references/restoration/modules/<module>.json`。
3. 如已读取清理强度档位则复用。
4. `img2img-material-regeneration.md` — 需要分区材质重建时的参考，普通编辑不必读取。

### 第五步：构建修复 Prompt

先按[修图模型选择与适配](../../WORKFLOW.md#修图模型选择与适配)取得本轮模型选择，再按其指南与真实接口适配下方内容；下方五模块是通用组织方式，不覆盖模型专用组织方式或用户锁定项。模型未确定前可查看原图和定位问题，不调用图片工具。

明确实际输入、修改目标与保留项，按模型适用方式组织自然语言。只有需要材质重建时才描述受损区域与目标表面；不要把保留细节和全面抑制纹理同时写进提示词。下列是可选组织示例，无需固定标签或顺序：

```
[核心主体描述]，[目标材质与适度细节]，[环境与背景]，[光影与氛围]，[摄影设备与调性]
```

**构建规则**：
1. 提取模块的 preserve/remove/rendering 与 style_keywords，融合为实际区域的材质描述，不机械堆叠关键词。remove 和负向词是候选缺陷，不是整张图的删除清单；只采用诊断确认且位于处理范围内的项，真实飞丝、皮肤状况、旧物划痕、反射和原有文字不因出现在词表就移除。
2. 将 `intensity_modifier` 的含义融入中文正文；light 不重建，standard 按需局部重建，deep 深度重建受损材质。
3. 将全局 `must_preserve` 的适用项写入主体、光影等对应模块，明确参考图是身份、结构、颜色和空间依据。
4. 强调背景去噪，避免模型继续复制原图脏纹；纯色平滑背景与有真实纹理的环境分别处理，不一律磨平。
5. 将 negative_prompt 转成与原图风格一致的质量要求。动漫保留线条和色块，老照片保留年代感和合理胶片颗粒，不套用摄影写实皮肤。
6. 仅添加与实际损伤和所选强度相符的条件段；按参考文件直接删改冲突措辞，不输出一条指令再用另一条取消它。
7. 按参考文件“细节分布与提示词收敛”检查五模块正文：说明精修区域，限制新增装饰细节，并将清理动作对应到实际缺陷；避免用泛化高清词代替修复要求。
8. 只添加与当前原图和模型有关的清理描述，保留正常纹理，不以磨皮和新增纹理互相补救。用户要求调整光影时描述期望的摄影情境与曝光，不能自动套高反差、强侧光或均匀柔光。

### 第六步：使用本轮选定模型编辑

调用前先按[逐张制作与六项验收](../storyboard-image-quality.md)筛查：生成图出现肢体畸形、参考画质不达标或虫纹与恶心异常细节泛滥，直接废弃，不以它为输入继续修复。调用次数及必要补修按[生成执行约束](../../SKILL.md#生成执行约束)执行，用户明确限额累计有效。先找全缺陷、划分区域并合并已知修复目标，争取第一轮完成；局部修复严格保护区域外内容，工具无法隔离时不冒充局部编辑。用户原图不擅自删除。

复用已确认支持本轮所选模型的接入，将干净原图及第五步已适配的完整提示词提交一次。引用方式、可用参数与返回方式遵循该接入的实际工具说明，不把 Codex 参数传给反重力或其他服务。提示词明确保持主体、构图与画面比例，默认中文；不能确认所选版本或编辑能力时先说明具体缺口，不自行换模型。原图无法引用时解决该引用问题，不改用上一轮劣化输出。

### 第七步：检查与交付

每次修复后集中做一次全图复检：目标缺陷是否解决、真实纹理是否保留、非目标区域是否保持不变、逻辑及相邻衔接是否成立。仍有问题时说明具体偏差，按[生成执行约束](../../SKILL.md#生成执行约束)处理必要补修，不重复确认已有授权。出现淘汰类缺陷立即废弃；补修仍失败或用户明确额度用尽则停止并清退失败输出，不通过切模块或回退重新计次。失败文件删除范围按质量卡执行。结果未知时，工具支持则查询已有任务，否则说明未知，不重复提交。完成当前图的采用或废弃再做下一张；缺少合格参考时只暂停真实依赖图。工具不可用或修复失败时说明未完成项，不将指令冒充成果。向用户展示可用结果，由用户决定采用，并简要说明：
- 识别的图片类型
- 使用的修复强度档位
- 核心修复方向（如"人像皮肤去脏+头发去结块+标准强度"）

仅需提示词时，按参考文件的编号格式交付中文正向正文和适用附加段；不需要为此先生成图片。对无法辨认的关键细节简短说明“无法确定”，不得宣称已精准恢复。生成结果若改变主体、颜色、构图、灯光或抹平真实纹理，应指出具体偏差，不能当作忠实修复成功交付。

## 关键约束

- **不重新设计**：只修复和干净化，不改变任何主体内容、风格、构图
- **模块按需加载**：不存在的元素不加载对应模块，避免过度修复
- **强度自动判断**：先诊断再选择强／中／弱，使用足够的最低档，用户指定优先
- **画幅约束**：在编辑指令中要求原图比例；工具未暴露尺寸控制时不虚构参数或保证像素一致，检查实际结果，比例偏差须说明
- **中文 Prompt**：默认使用五模块中文正文；配置内英文关键词作为语义素材，按需保留英文去噪强调词
- **配置为基准而非逐字复制**：从 JSON 中提炼修复要求，转化为自然流畅的生成指令
- **修复与保留的平衡**：去除脏污伪影的同时，必须保留真实材质纹理。干净不等于磨平，清晰不等于锐化
