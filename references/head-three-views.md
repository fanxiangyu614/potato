# 头像三视图

来源：用户提供的 `external-source://大头三视图.txt`，原文件未随技能分发。本文件保存可复用流程与中文提示词；执行不依赖原文件。

## 目标与输入

- 根据同一人物的一张或多张参考图，制作正面（0°）、45°斜侧面、90°纯侧面三张独立图片，不把背面当作第三视图，不默认拼成一张三联图。45°与90°默认朝同一侧；用户指定方向或排版时遵从。
- 锁定参考人物的脸型、五官比例、年龄感和识别特征，三张保持同一发型、发色、表情基调、光照与头部尺度；不让美化或风格探索改变身份。未提供人物参考图时请求上传，不凭空宣称还原本人。
- 原文造型预设为“利落低束半扎造型，空气刘海，轻微凌乱、不刻板、时尚”。用户要求原文造型或未指定造型且希望重新设计发型时可采用；其余情况默认保留参考发型，当前指定优先。无论选哪种，三张一致。
- 只要提示词时提供对应阶段的可复制提示词；要求出图时使用参考图继续生成。图像执行遵守可用图像工具及相关技能的要求，不把提示词交付称为已经出图。

## 第一阶段：证件照式人物三视图

制作三张头肩肖像，采用干净统一的证件照式背景和均匀布光；这里描述视觉风格，不宣称符合实际证件办理规范。三张只改变观察角度，避免更换人物或发型。

可复制提示词（将花括号替换为当前已确定内容）：

```text
以提供的同一人物参考照片为身份依据，制作三张独立的证件照风格头肩肖像：第一张正面0°，第二张45°斜侧面，第三张90°纯侧面，后两张均朝{同一方向，默认画面左侧}。准确保留参考人物的脸型、五官比例、眉眼、鼻形、唇形、下颌与年龄感，不换脸、不夸张美化。发型为{保留参考发型／用户指定发型／原文低束半扎空气刘海预设}，三张发型、发色及发际线一致。自然中性表情，视线随头部方向自然朝前，固定肩部以上构图和头部尺度，背景干净统一，布光柔和均匀、肤色一致，保留自然皮肤细节。只改变视角，不添加文字、水印或额外人物。分别交付三张图片。
```

## 相似度确认与修正

展示第一阶段结果后询问：“这组三视图像本人吗？像的话继续做透明背景的纯面部三视图；不像请指出需要调整的位置。”等待用户确认，不自行用“看起来像”替代用户判断。提示词交付时说明此为用户使用后的衔接步骤，不声称看过未提供的生成结果。

用户反馈不像时，依据反馈修正第一阶段并再次确认；每次反馈先修正一轮，不自动无限重试。没有具体反馈时可问最需要修正的部位。用户明确确认、已提供确认过的三视图，或明确要求直接做第二阶段时继续，不重复索要确认。

## 第二阶段：透明背景纯面部三视图

以原始人物参考和已确认的第一阶段结果保持身份与视角一致，生成正面、45°、90°纯侧面三张面部特写。仅保留面部，颈部、身体、服装与背景均透明；不沿用第一阶段的头肩构图，也不擅自保留完整发型、扩展成带脖子的头像贴纸。用户明确要求保留头发或完整头部时按其指定范围执行。

可复制提示词：

```text
以原始人物参考照片及已确认的三视图为依据，制作三张独立的纯面部特写：正面0°、45°斜侧面、90°纯侧面；方向与已确认版本一致。仅面部可见，准确保留同一人物的脸型、五官比例与细节，不改变身份。头部尺度、面部构图及面部光照与对应参考视图一致。颈部、身体、服装和背景全部移除并设为透明，面部以外不保留头发或其他元素。不得用白底、黑底或棋盘格图案冒充透明背景。输出三张具有真实透明通道的PNG图片，不拼图，不添加文字或水印。
```

检查实际交付是否为三种正确视角、身份一致，第二阶段是否含真实透明通道。工具不能输出真实透明背景时明确说明具体限制，不把视觉上的空白背景标为已透明。
