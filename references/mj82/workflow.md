# 仿 Midjourney 8.2 图生图优化模块

仿 Midjourney 8.2 高端美学的图生图优化 Skill。自动区分人物肖像与背景场景，套用对应配置生成优化后的图片。

## 交付与授权

审阅或维护本模块 不触发图像生成。只要分析就交付分析，只要提示词就交付可用指令；用户要求优化图片且已有可引用原图时，自动分类并直接完成编辑，不在分类、选词或生成前重复确认。

只在缺少目标图片、明确要求无法兼容或下一步超出授权时询问；可依据画面决定的类别和强度自行选择。工具不可用时交付已完成的优化指令并说明图片尚未生成，不把提示词当作图片任务已完成。

与内部脏图修复模块联用时，它负责目标缺陷，本模块 负责用户已授权的光影、色调和光学美学；用户要求保留的项目不被配置覆盖。与内部风格探索模块联用时只采用相关方向，优先合并为一次编辑，除非用户要求分阶段结果或多个版本。

## 工作流

### 第一步：图片分类

查看用户提供的图片，判断图片类型：

**人物肖像图（Portrait）**——满足以下任一条件：
- 画面主体为人脸，面部占据画面显著比例（>20%）
- 可见清晰的五官（双眼、鼻子、嘴唇），面部为视觉焦点
- 半身像、特写、头像、时尚人像

**背景/场景图（Scene）**——满足以下任一条件：
- 无突出人脸，或人脸仅为点缀且占比极小
- 主体为风景、建筑、室内空间、产品、静物、城市街景
- 以环境氛围、空间感、材质纹理为核心表达

**模糊边界处理**：若图片同时包含人物和场景，以人物是否为绝对视觉焦点判定——人物面部清晰且为构图中心则归为 Portrait，否则归为 Scene。

### 第二步：加载对应配置

- **Portrait** → 读取 `portrait-config.json`
- **Scene** → 读取 `scene-config.json`

### 第三步：构建优化 Prompt

基于加载的配置，按最终交付语言构建优化指令（默认中文，用户指定语言优先）。Prompt 结构：

```
[风格定位] + [核心视觉语言] + [光影要求] + [色调要求] + [光学质感] + [专属细节(仅Portrait:皮肤/头发/签名表面效果)] + [氛围要求] + [画质要求] + [style_keywords] + [柔光镜滤镜]
```

**构建规则**：
1. 从配置中提取适用模块的核心描述，整合为连贯的指令，用户指定语言优先
2. 从 `style_keywords` 选择与画面及用户目标一致的核心词；去重并删除冲突项，不要求全部堆叠。配置中的肤色、暗背景和浅景深是可选审美基准，不覆盖身份肤色、可见场景内容及明确保留项。
3. 仅在当前任务明确采用此预设时，默认加入 55% 柔光镜风格描述；不把该预设外溢到普通剧情资产或修改任务。用户指定强度或要求无柔焦时按用户要求。使用 `apply 55% strength soft focus diffusion filter, gentle glow on highlights while preserving core subject detail, organic optical softness`，人像可将 subject 换成 facial；该百分比是提示词语义，不是实际设置的滤镜参数。
4. 负面提示词（negative_prompt）中的禁忌项按实际问题转为无冲突的描述；例如皮肤塑料感优先写现场光下自然肤色过渡与合理反射。只有近景对焦与清晰度支持时才取用真实纹理描述，不以整脸添加毛孔替代诊断。
5. Prompt 聚焦于风格/光影/质感的改变，**保留参考图的主体、构图、姿势、服装、场景内容不变**

### 第四步：使用当前宿主的图像编辑工具

沿用用户已选且实际可用的编辑入口，传入原图及第三步的整合指令；参考图片、画幅和区域参数按该工具真实接口填写。不预设工具名称或参数键，不把仿MJ审美处理冒充实际调用Midjourney。原图只有对话附件时按宿主可用的附件引用机制处理；无法取得有效编辑输入才请用户补充。没有可用编辑工具时交完整提示词并说明未生成。

### 第五步：交付

生成后按[逐张制作与六项验收](../storyboard-image-quality.md)检查逻辑与相邻衔接、人物结构、参考画质和异常纹理，并核对用户要求的美学变化。肢体畸形、画质不达标或虫纹与恶心异常细节泛滥直接废弃。实际调用与补修次数统一按[生成执行约束](../../SKILL.md#生成执行约束)累计，本模块不另发额度；新美学设计不能成为重复修图的借口。先找全问题、划分区域，争取一次修好；局部编辑区域外不动，获准补修时仅处理已确认的剩余问题。每次修后集中复检，出现淘汰类缺陷或额度用尽仍不合格即废弃。先完成当前图处理再做下一张，依赖缺失图的后续暂停。状态未知查询原任务（若支持），否则说明未知，不重复提交。不能把工具返回等同于合格；失败文件按质量卡处理，保留用户原图。

向用户展示实际结果，并简要说明：
- 识别的图片类型（Portrait / Scene）
- 套用的核心优化方向（如"人像朦胧油光+雕刻光影"或"场景氛围深度+光学柔化"）

## 关键约束

- **不改变主体内容**：只优化美学风格（光影、色调、质感、氛围），不替换人物、不改变姿势、不改变场景物体
- **柔光基准**：默认 55% 提示语，用户指定优先；不声称已经精确施加数值滤镜
- **原图比例**：指令要求保持，不擅自裁剪或拉伸；工具无尺寸参数时不虚构参数，按实际结果核对并说明偏差
- **提示词语言**：默认中文，用户语言要求优先；联用时采用最终交付语言，不为中英文各重复生成一次。英文风格词可保留作语义锚点，不声称英文效果必然更好
- **配置为基准而非逐字复制**：从 JSON 配置中提炼核心视觉要求，转化为自然流畅的生成指令，不要把 JSON 结构直接粘贴进 prompt
