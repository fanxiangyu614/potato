# 土豆拍照

独立通用的 AI 图片创作 Skill，机器标识：`tudou-photo`。

支持随机拍照、写真、COS、巨构环境人像、生图、改图、修复、人物妆造、场景道具和封面海报；保留真人、2D、3D、CG及相容的混合风格。

## 使用

下载或克隆整个仓库，放入所用助手的技能目录；支持直接读文件的助手也可读取根目录 `SKILL.md`。不要只复制入口文件。

直接说：

- 土豆拍照，随机拍三张。
- 土豆拍照，用我的脸拍写真。
- 土豆拍照，来张巨构人像。
- 土豆拍照，随机COS。
- 土豆拍照，修一下这张图。
- 土豆拍照，只给提示词。

支持技能命令的助手可使用 `$tudou-photo`。具体安装位置由所用助手决定。

## 运行条件

实际出图使用当前助手已提供的图片生成/编辑工具；本仓库不包含模型、账号、API密钥或生图服务。没有图片工具时可完成方案与提示词。

本地抽样脚本需要 Python 3.10+，只使用标准库。从仓库根目录运行：

```bash
python -B -X utf8 scripts/random_photo.py validate
python -B -X utf8 scripts/random_photo.py sample --source local --aspect-ratio 16:9 --count 1
```

脚本输出创意底稿，不直接生图；执行者须按Skill完成搭配核对、妆造和最终提示词。

## 文件

- `SKILL.md`：技能入口
- `WORKFLOW.md`：按任务读取的工作流
- `references/`：规则、文字库与工艺资料
- `scripts/`：抽样、风格探索及能力候选整理
- `agents/`：可选的助手展示配置

这是从超级图片创作舱导出的独立Skill，不依赖土豆风暴插件。目录与脚本检查不代表实际图片效果已经验证。

部分电影工艺资料附有独立来源、署名和许可要求，使用时请保留，见 [来源与许可](references/craft/cinematic-visual/sources.md)。
